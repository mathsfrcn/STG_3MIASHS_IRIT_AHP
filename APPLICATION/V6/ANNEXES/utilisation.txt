Mise en place :
	1. Paramétrage du serveur
		1.1. Changer l'adresse de l'application dans le code du formulaire "UsfCreationEtape3"
		1.2. Créer un nouveau fichier de paramétrage
	2. Lancer une instance du serveur "run.py" => le site devient accessible (l'adresse du site est indiquée dans le terminal python)
	3. Attendre les réponses
	4. Une fois toutes les réponses obtenues :
		4.1. Le fichier csv de classement est généré
		4.2. Le graphe des alternatives est généré
	5. Tous les décideurs ont maintenant accès au classement
	6. Le superviseur peut alors renseigner l'alternative retenue (sortie en fichier txt)
